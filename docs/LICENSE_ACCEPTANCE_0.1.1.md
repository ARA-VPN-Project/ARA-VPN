Состав: LICENSE, NOTICE, TRADEMARKS.md, SOURCES.md, CONTRIBUTING.md,
licenses/INVENTORY.json, licenses/NATIVE-SOURCES.json и licenses/third-party/.
Независимые компоненты OpenVPN и wireguard-tools берутся из Debian, а не
переупаковываются как собственный код ARA.

В текущей поставке обновлено только содержимое документации пакетов.
Доказана неизменность всех прочих payload: бинарники, конфиги, systemd-юниты,
права и скрипты сопровождения. Изменение SHA-256 .deb ожидаемо; контрольные
суммы выпуска пересчитаны. Проверенный Go-код не менялся, поэтому повтор
сетевой кампании и перезапуск боевых пользователей в этом проходе не требуются.

Воспроизведение проверки:

```sh
python3 release/check-licenses.py --dist dist/v0.1.1
```

Исходные архивы вместе с бинарниками должны быть доступны в одном публичном
выпуске. Обязательная проверка настоящих GitHub-ссылок выполняется при публикации,
по окончательному адресу ARA-VPN-Project/ARA-VPN. На момент лицензионного
прохода публикация ещё не выполнялась; текущий адрес указан в PUBLICATION.md. Подготовка комплекта не заменяет отдельную
проверку будущих обновлений зависимостей и не утверждает битовую воспроизводимость
upstream native engine.

Технические границы остаются в ACCEPTANCE_0.1.1.md: Docker runtime, физический ARM,
телефонные приложения и полевые DPI-проверки не объявляются пройденными.
