# Стартовая страница ARA 0.1.1

В Настройки → Стартовая страница доступны нейтральная заглушка, свой текст и Index. Свой заголовок ограничен 120 символами, текст — 6000. Переносы строк сохраняются. HTML и скрипты из текста не исполняются. Страница видна всем посетителям корня сайта, секретный адрес панели на неё не добавляется.

Настройки хранятся в public-page.json в каталоге состояния панели и входят в резервную копию. Сохранение действует без перезапуска. Переключение языка панели не переводит пользовательский текст.

Для CLI подготовьте JSON с полями mode (neutral/custom/index), title и text. Затем выполните от пользователя панели ara-control --state-dir /var/lib/ara-control --set-public-page /path/to/page.json. GET и POST /api/v1/public-page используют обычную административную авторизацию, сессия браузера требует CSRF.

## Страны

В форме добавления ноды выбирайте название страны. Двухбуквенный код подставляется автоматически. Страна — метка администратора, проверка геолокации IP выполняется отдельно. Роль ноды также выбирается отдельно.
