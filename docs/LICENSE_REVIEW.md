# Лицензирование ARA VPN 0.1.1

10 ноября 2026 владелец выбрал **AGPL-3.0-or-later** для собственного кода ARA.
Полный неизменённый текст находится в корневом LICENSE. NOTICE описывает область
действия; сторонние компоненты не перелицензируются. Коммерческое использование
разрешено на условиях соответствующих лицензий. Правила бренда — TRADEMARKS.md.

Основной источник сведений о поставляемом коде — licenses/INVENTORY.json:
объединение Go build information 12 исполняемых файлов из восьми Debian-пакетов
amd64/armhf. Это 160 точных пар module/version и два toolchain. Исходные ZIP
модулей проверены по embedded h1; main-модуль sing-box не содержит h1, поэтому
его SHA-256 записан отдельно без ложного утверждения о подписи upstream.

Движок sing-box 1.14.4 остаётся GPL-3.0-or-later. Его оригинальное уведомление
о правах и имени сохранено, полный GPL включён отдельно. Поддержка NaiveProxy
в upstream-сборке включает Cronet. Для этой нативной части отдельно сохранены
исходники SagerNet/naiveproxy на commit, указанном gitlink в соответствующих
cronet-go ревизиях, и уведомления Chromium/зависимостей. Реестр —
licenses/NATIVE-SOURCES.json. Проверка лицензий не означает, что ARA включает
NaiveProxy для каждого соединения или запускает браузер.

Все upstream LICENSE/NOTICE/COPYING/COPYRIGHT/PATENTS, найденные в точных
архивах, сохранены под licenses/third-party. Исходные архивы дополнительно
содержат встроенные copyright-комментарии и прочие материалы авторов.
OpenVPN и wireguard-tools устанавливаются как самостоятельные пакеты Debian;
их бинарники не входят в восемь ARA .deb. Их документация и лицензии сохраняются
пакетным менеджером Debian. Системные базовые слои Docker сохраняют собственные
лицензии. Docker runtime не объявляется проверенным этим лицензионным проходом.

Публичный выпуск обязан предоставлять все source-ассеты рядом с бинарниками
без дополнительной платы. Состав и способ восстановления — SOURCES.md.
Настоящая публикация и проверка скачивания по финальному GitHub-адресу выполняются
только по отдельной команде владельца. Независимая битовая воспроизводимость
upstream native engine в этом проходе не доказана и не заявляется.
