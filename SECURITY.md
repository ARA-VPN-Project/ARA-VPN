# Безопасность

Для уязвимостей используйте вкладку Security → Report a vulnerability в этом
репозитории. Не публикуйте пароли, SSH/TLS-ключи, административные URL, рабочие
ссылки подписок и данные пользователей в обычных issues.

Укажите версию, роль ноды, условия воспроизведения и ожидаемую границу доступа.
Используйте вымышленные адреса и минимальный пример. Наличие скриншота или
ошибки API само по себе не доказывает эксплуатацию: опишите наблюдаемый эффект.

Поддерживаемый публичный выпуск: 0.1.1. Обновления зависимостей требуют нового
контроля исходников, лицензий, подписей и артефактов; не заменяйте pinned engine
произвольным системным бинарником.
