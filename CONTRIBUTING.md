# Contributing to ARA VPN

Submit changes under AGPL-3.0-or-later, the same terms as ARA-authored code.
Retain existing third-party licenses and copyright notices. Do not submit code,
fonts, icons, datasets or other material without permission to redistribute it.
Contributors retain their copyrights; no exclusive assignment is implied.

Follow AGENTS.md for engineering work. Include focused verification appropriate
to the change, keep UI and CLI behavior consistent, and never include real keys,
customer data, subscription links or private infrastructure in a contribution.
Dependency or engine updates must refresh the exact binary-derived inventory,
source archives, notices and release checksums before distribution.
